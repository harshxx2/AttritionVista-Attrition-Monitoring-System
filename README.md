## ⚡ MISSION BRIEFING
**AttritionVista** is not just a dashboard—it is a **Strategic Predictive Ecosystem**. Designed for the modern C-Suite, it transforms chaotic HR data into a high-fidelity narrative of organizational health. It identifies talent flight risks before they happen, using a combination of **Structural Intelligence** and **Lifecycle Heuristics**.

### 🛠️ CORE INTELLIGENCE NODES
- 🏢 **DEPARTMENT HUB (SYMMETRY 2.5)**: A dual-pane 50/50 intelligence matrix correlating role performance with employee lifecycle dynamics.
- 🎯 **RISK INDICATOR ENGINE**: Real-time identification of flight risks triggered by tenure lag and promotion cycles.
- 🧪 **RISK SIMULATOR**: An interactive heuristic sandbox for projected workforce instability modeling.
- 📊 **TABLEAU NEXUS**: Deep-integrated Embedding API v3 synchronization across all operational nodes.

## 🚀 INITIALIZING THE HUB

### 1. CLONE THE DOSSIER
```bash
git clone https://github.com/harshxx2/AttritionVista-Attrition-Monitoring-System.git
```

### 2. SYNC DEPENDENCIES
```bash
npm install --force  # Force sync for enterprise compatibility
```

### 3. DEPLOY LOCAL HUB
```bash
npm run dev # Launches the Intelligence Stream at localhost:5173
```
